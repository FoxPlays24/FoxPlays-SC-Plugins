# FoxPlays's Sven Co-op Plugins

This is my repository that stores all the plugins I've created for Sven Co-op.
You can select plugin's folder and see more details about them.

Currently there are 3 plugins:

- **FixMyChat** - send chat messages in Cyrillic/Hieroglyphics without need to use Latin characters
- **KYS** - kill your friends with lightning!
- **PlayerHeight** - set your custom view height for playermodels on the server
